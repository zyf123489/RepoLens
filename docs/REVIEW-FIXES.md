## 保留范围与限制

- `App.tsx` 仅增加扫描失败状态的展示，没有拆分组件或状态管理。
- Rust 实际验证工具链为 stable 1.99.1，Cargo 的支持下限声明保持 1.99；未据此宣称已测得理论最低可编译版本。源码已使用 1.82 起稳定的 `Option::is_none_or`，依赖可能要求更高版本；旧工具链兼容需另行验证。
- 单条查询可以避开其他损坏记录，但完整列表仍会报告数据库内容损坏；本次没有增加自动跳过、修复或丢弃记录的行为。
- 配置包含关系仍由 Git 求值；相关来源文件变化可能要求重新预览，即使生效身份没有变化。多个外部来源文件不共享目标 config.lock，仍保留写入前复核和写入后验证。
- 扫描异常收尾不涵盖进程终止、panic=abort 或无法展开的致命故障。线程创建失败路径已处理，未通过耗尽系统线程资源作实测。
- 原有 10/100/500 性能数字属于修复前基线；本次不宣称整体刷新性能指标已改善。其他 OS、干净环境安装卸载、签名、公证和正式发布仍待验收。
